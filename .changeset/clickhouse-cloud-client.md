---
"clickhouse-cloud": minor
---

Add a typed client for the ClickHouse Cloud API, generated from the OpenAPI spec ClickHouse publishes at https://api.clickhouse.cloud/v1, so organizations, services, backups, API keys and ClickPipes can be managed from TypeScript without hand-written request code. It authenticates with an API key ID and secret over HTTP basic auth and ships optional Effect bindings.
