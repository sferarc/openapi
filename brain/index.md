# Brain

Knowledge vault for the openapi repository, readable as an Obsidian vault. One topic per file, wikilinks for cross-references. It records how the generated clients are produced and released and why the repository is shaped the way it is, with a source path, commit or pull request behind every claim. Where something is not known, the note says so.

The root `README.md` and each package's `README.md` are the user documentation. These notes are for someone changing the generator, a client, the website or the release.
